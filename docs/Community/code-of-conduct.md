# Code of Conduct

BlanketOps Environments follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
in every project space: the repositories, their issues, pull requests and
discussions, and any chat, meeting or event held for the project.

To report a violation, email the maintainers at **ntlaletsi86@gmail.com**.
Reports are handled confidentially.

The project's [`CODE_OF_CONDUCT.md`](https://github.com/blanketops/environments/blob/main/CODE_OF_CONDUCT.md) is the source of
truth, including how reports involving a maintainer are handled.
