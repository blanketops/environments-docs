# Community

BlanketOps Environments is developed in the open under the Apache License 2.0,
and contributions are welcome — code, documentation, reviews, bug reports and
design discussion.

The project's community and governance files live in the
[`environments`](https://github.com/blanketops/environments) repository and
apply to every repository of the project. These pages summarise them and link
to the source.
