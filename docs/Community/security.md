# Security

Please **do not** report security vulnerabilities in a public GitHub issue.
Email **ntlaletsi86@gmail.com** with a description, the affected repository
and version, and steps to reproduce. You should receive an acknowledgement
within 5 business days.

Only the latest minor release is supported — currently **0.8.x** for
`environments`, and the latest release of each other repository.

Supported versions, the response process and the disclosure policy are in
[`SECURITY.md`](https://github.com/blanketops/environments/blob/main/SECURITY.md).
